What Flock Cameras Do

Flock Safety makes automated license plate readers (ALPRs). They continuously photograph vehicles and turn the images into searchable data.

What they capture

  • License plate number
  • Make, model, color, body type
  • Distinctive features (stickers, racks, damage…)
  • Exact time + location of the pass

No facial recognition — focus is on the vehicle.

How the network works

  • Used by police, HOAs, businesses, schools
  • Default retention ≈ 30 days (agencies can set longer)
  • Agencies can search each other’s data + receive hotlist alerts
  • Flock claims 120k+ cameras across 49 states
